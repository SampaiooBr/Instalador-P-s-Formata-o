# 🚀 SAMPAIOOBR - Central Pós-Formatador

O **SAMPAIOOBR - Central Pós-Formatador** é uma ferramenta web interativa e automatizada desenvolvida para agilizar a instalação de programas essenciais, runtimes, plataformas de jogos e utilitários de suporte logo após a formatação do Windows.

## ✨ Principais Funcionalidades

* **🛠️ Seleção Dinâmica por Categorias:** Organização limpa e intuitiva dividida entre Programas Essenciais, Runtimes (Visual C++, DirectX), Gaming & Launchers (Steam, Epic, Discord, EA App) e Ferramentas de Suporte.
* **🎨 Personalização de Ícones:** Sistema integrado para alterar os ícones visuais de qualquer card de aplicativo de forma personalizada com salvamento em `localStorage`.
* **⚙️ Automação via Winget:** Geração instantânea e inteligente de scripts em lote (`.bat`) ou comandos prontos para o PowerShell para instalação silenciosa e automatizada de todos os softwares selecionados.
* **💾 Exportação de Comandos:** Opção para copiar diretamente o comando em lote para a área de transferência ou baixar o arquivo de instalação executável.
* **💖 Apoio / PIX:** Botão integrado com modal interativo para facilidade de contribuição via PIX do projeto.

---
*Desenvolvido para otimizar o tempo de configuração de máquinas novas ou recém-formatadas com alta performance, design moderno em Dark Mode e praticidade total.*
